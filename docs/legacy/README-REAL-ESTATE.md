# دفتر رهنمای معاملات | Real Estate Office

این نسخه از SafarPro برای ساخت سیستم رهنمای معاملات آماده شده است.

## بخش‌های موجود
- داشبورد ساده
- تنظیمات
- سطل زباله
- ادمین مرکزی در مسیر `/admin`

ماژول‌های سابق سیاحتی از مسیرهای اصلی، صفحات و سایدبار حذف شدند. بخش سرور، احراز هویت، اشتراک، دیتابیس، store و پنل ادمین برای جلوگیری از قطع امکانات عمومی حفظ شده‌اند. ذخیره‌های قدیمی LocalStorage به صورت خودکار حذف نمی‌شوند. این نسخه هنوز دارای ماژول‌های عملیاتی ملکیت/قرارداد نیست و صرفاً پایه آماده توسعه آن‌ها است.

راه‌اندازی: `npm install` سپس `npm run dev`؛ بررسی ساخت: `npm run build`.
