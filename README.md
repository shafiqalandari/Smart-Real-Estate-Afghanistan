# Smart Real Estate Afghanistan

**سیستم رهنمای معاملات و کرایی**، برای دفاتر مدیریت جایداد در افغانستان.

این پروژه از پروژه قبلی توسعه داده شده و شامل داشبورد، جایدادها، مشتریان، معاملات، حسابداری، گزارش‌ها، ریسایکل‌بین، تنظیمات، مدیریت مرکزی و حساب ورود دفتر است.

## نصب و اجرا

1. Node.js و PostgreSQL را نصب کنید.
2. با `npm install` وابستگی‌ها را نصب کنید. این نسخه فایل قفل قدیمی ناسازگار ندارد و `npm install` قفل جدید می‌سازد.
3. از روی `.env.example` فایل `.env` بسازید و PORT، PostgreSQL و رمزها را تنظیم کنید. پورت پیش‌فرض API اکنون 3021 است و Vite نیز همان پورت را استفاده می‌کند.
4. با `npm run db:migrate` مایگریشن‌ها را اجرا کنید (قبل از آن بکاپ بگیرید).
5. با `npm run dev` پروژه را به‌صورت محلی و با `npm run build` نسخه تولیدی را آماده کنید.

## ورود به سیستم

- صفحه ورود کارمند / دفتر در مسیر `/` است.
- ورود ادمین مرکزی در مسیر `/admin/login` است.
- نام برنامه، لاگین، PWA، اشتراک‌ها و منوها نام تجارتی جدید دارند.
- برای سازگاری نشست‌ها و دیتابیس‌های قبلی، کلیدهای تخنیکی قدیمی تغییر نکرده‌اند.

لطفاً `BRANDING-UPDATE.md` و `REAL-ESTATE-STATUS.md` را بخوانید. بعضی قابلیت‌های PRD هنوز نیازمند تکمیل و تست روی دیتابیس واقعی‌اند.

برای اصلاح صفحه ثبت‌نام و خطاهای اتصال به فایل `LOGIN-FIX-GUIDE.md` مراجعه کنید.
